# PCL feedback and takedown requests

This repository collects **feedback** and **takedown requests** for the data releases of the **Persian
Computational Lexicon (PCL)**. It holds no code and no data — only issues.

## What PCL is

PCL is a sense-based lexicon of Persian (فارسی): headwords, senses, part of speech, pronunciations per sense,
morphology, sense links and verb stems. Every row names its source and licence. The public releases contain verified
records only. The data are licensed GPL-3.0-only; the sources keep their own licences and are credited in the
release's `ATTRIBUTION.md` and `NOTICE`.

## Where the data is

- Zenodo: [10.5281/zenodo.23493197](https://doi.org/10.5281/zenodo.23493197) (PCL v0.1.1; the DOI always resolves to the
  latest version).

## Request a takedown

If you hold rights in material that appears in a PCL release and do not want it redistributed, open an issue with the
**Takedown request** template (title prefix `[takedown]`):
https://github.com/manaderakhshan-cloud/PCL-feedback/issues/new/choose

Please say which source or work you hold rights in, which entries or files are concerned (examples or a list), and how
we can reach you. The request is acknowledged, the matching rows are identified, and they are left out of the public
exports at the latest 30 days after the acknowledgement. The procedure is described in the release's `TAKEDOWN.md`.

## Other feedback

Errors in an entry, a pronunciation or a licence credit, and other comments: open an issue with the **Feedback**
template.

Please do not post personal data of other people in issues; issues here are public.
